###  [Blog 1 - AWS LAMBDA SELF-STUDY REPORT FOR BEGINNERS](3.1-Blog1/)
This beginner-friendly report highlights AWS Lambda as an ideal entry point for students exploring cloud computing, demonstrating how its serverless, event-driven, and pay-per-millisecond model eliminates infrastructure management while emphasizing the importance of modular microservices over large, monolithic backend designs.

###  [Blog 2 - WHAT HAVE I LEARNED AFTER EXPERIENCING AWS IOT CORE?](3.2-Blog2/)
Shares our experience transitioning to AWS IoT Core for hardware projects, explaining how it revolutionizes development by utilizing the lightweight MQTT protocol for low-power microcontrollers like the ESP32, enforcing robust security through X.509 certificates and IAM policies, and seamlessly integrating with the broader AWS serverless ecosystem.

###  [Blog 3 - WHAT DID I LEARN AFTER EXPERIENCING AWS IOT CORE?](3.3-Blog3/)
This blog post shares my experience optimizing embedded systems (such as ESP32) using AWS IoT Core, highlighting its ability to deliver ultra-lightweight data via the MQTT protocol, its rigorous mTLS security mechanism using X.509 certificates, and its flexibility in connecting directly to serverless services like AWS Lambda and RDS.
